# SOLAR BASED IOT BASED WIRELESS EV CHARGING STATION

![Project Image](./Real%20Photos%20and%20Videos/V_sem_image_1.jpeg)

### *Project Description:*

A Prototype of a charging station for Wireless Charging Electric Vehicles which is integrated with IoT which reduced human interruption
in the process of charging EV then the Charging station is powered with solar energy which is a green renewable source of energy. 

We have shown to charging slots one is automated with IoT and other one requires manual control.
